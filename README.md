# 📸 모먼트컷 v6 — 전·후면 카메라 + 미리보기 고정 + 카카오톡 저장 대안

촬영 전 레이아웃 선택, 기본 4x6 두 장 출력, 3·5·10초 자동/수동 촬영, 개별 재촬영, 전체 초기화, 다양한 기본 프레임 컬렉션, PNG 다운로드, 사진 공유 QR, 관리자 프레임 업로드/레이아웃/문구 관리.

## 접속 주소

- `/` — 일반 사용자의 포토부스
- `/admin.html` — **관리자 전용 프레임 스튜디오** (비밀번호 필요)
- `/api/health` — 서버 상태 (`/health`는 로컬 서버용)

## 이번 버전 변경 사항

1. `홈 → 촬영 설정 → 사진 촬영 → 꾸미기 → 완성` 순서입니다. 레이아웃을 **처음 단계에서 먼저 선택**하며, `basic 4-cut`, `basic 6-cut`, `wide 4-cut`, `layer 4-cut`, `film 3-cut` 기본 레이아웃을 제공합니다.
2. 기본 레이아웃인 `basic 4-cut`은 **4x6 세로 용지에 가로 비율 사진 4컷짜리 2x6 스트립 두 장이 나란히 출력**되도록 구성했습니다. 각 스트립의 하단에 `Feel;m` 문구가 따로 나타나며, 사진 영역을 위·아래로 확장해 큰 여백을 줄였습니다. `wide 4-cut`은 **6x4 가로 비율**로 조정했습니다. 세로 레이아웃을 선택하면 촬영 미리보기도 세로 비율로 바뀝니다.
3. 타이머는 **3초 · 5초 · 10초 · 수동**을 지원합니다. 사진 하나만 **재촬영**할 수 있고, 별도로 **처음부터 초기화** 버튼을 두어 사진·필터·스티커·문구·로고·레이아웃을 모두 리셋합니다.
4. 기본 문구 초기값은 제목 `Feel;m`, 작은 메시지 `our little moment`로 바꾸었고, 하단 문구 영역을 더 넉넉하게 확보했습니다. 기본 프레임 컬렉션은 **베이직 / 러블리 / 무드 / 시즌** 카테고리별로 접고 펼칠 수 있으며, 모바일에서는 한 번에 하나의 카테고리만 펼쳐집니다.
5. 관리자는 `/admin.html`에서 로그인한 후 프레임을 추가·수정·삭제할 수 있습니다. 출력 가로/세로 크기, 컷 수, **사진 영역 드래그·크기 조절**, 프레임 배경색, 이미지 오버레이 업로드, 문구·문구 위치·글씨 크기·색상 변경 등을 지원합니다.
6. 관리자가 저장한 프레임은 일반 사이트의 **꾸미기 → 프레임 → 관리자 특별 프레임**에 나타납니다. 관리자의 문구를 기본값으로 불러오며 사용자는 개인 사진에 맞게 바꿀 수 있습니다.
7. 출력 이미지 내부에는 `basic 4-cut` 같은 레이아웃 이름이나 인쇄 형식 배지가 들어가지 않습니다. (레이아웃 이름은 촬영 설정 UI에만 표시됩니다.)

## GitHub + Vercel 배포

**[GITHUB-VERCEL-배포가이드.md](./GITHUB-VERCEL-배포가이드.md)**에 초보자를 위한 단계별 설명이 있습니다.

GitHub 저장소 최상위에 `vercel.json`, `package.json`, `public/`, `api/`, `frame-store.mjs`, `admin-api.mjs`, `vercel-api.mjs` 등이 있어야 합니다. ZIP 자체를 업로드하지 말고 압축 해제한 **내부 파일**을 올리세요. 중첩된 `momentcut/momentcut/` 폴더를 만들지 마세요. `render.yaml`은 필요하지 않습니다.

Vercel:

| 항목 | 값 |
| --- | --- |
| Framework Preset | `Other` |
| Root Directory | `./` |
| Build Command | 비워두기 |

### 관리자용 필수 환경 변수

Vercel 프로젝트의 **Settings → Environment Variables**에 아래 둘을 추가하세요. 반드시 비밀 값으로 설정하며 GitHub 파일 안에 적지 마세요.

- `ADMIN_PASSWORD` — 관리자가 입력할 **길고 추측하기 어려운 비밀번호**. 고정 기본 비밀번호는 제공하지 않습니다.
- `ADMIN_SESSION_SECRET` — 로그인 쿠키 서명용 임의의 비밀 문자열(권장 32바이트 이상의 난수). 예: 로컬 터미널에서 `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` 실행하여 출력값 사용.

필수 값이 없다면 관리자 API는 503으로 거부합니다. 로그인 후 8시간 동안 `HttpOnly; SameSite=Strict` 쿠키로 인증합니다. 관리자 변경 API는 비밀번호 인증 없이 사용할 수 없습니다. 운영 시 강력한 비밀번호를 사용하고 서비스에 맞는 추가 로그인 보호(요청 제한 등)를 적용하세요.

### 관리자 프레임 영구 저장 · QR 공유

**Vercel Storage → Blob → Private store**를 프로젝트에 연결하고, 자동 등록되는 `BLOB_READ_WRITE_TOKEN`이 있는지 확인하세요. **새 배포**를 트리거하세요. 프레임 정보와 업로드한 오버레이 이미지는 **Private Blob**에 저장됩니다. 일반 방문자는 이미지 조회용 API를 통해 공개된 프레임만 불러옵니다. 업로드한 오버레이는 WEBP로 최적화되어 최대 1.5MB입니다. 이미지 변경 직후 Blob 캐싱에 따라 반영에 최대 약 1분이 걸릴 수 있습니다.

일반 촬영/PNG 다운로드는 Blob 연결 없이 동작하지만, **관리자 프레임 저장 및 QR 사진 공유**는 Blob 연결이 필수입니다. Blob 한도/사용량에 따라 비용이 발생할 수 있습니다.

## 로컬 개발

Node.js **20 이상** 권장:

```bash
npm install
# 아래 값은 예시이므로 실제 서비스에 사용하지 마세요.
export ADMIN_PASSWORD='local-only-password-change-me'
export ADMIN_SESSION_SECRET='long-random-session-secret-for-local-dev-only'
npm run check
npm start
```

Windows PowerShell에서는 `export` 대신 `$env:ADMIN_PASSWORD = "..."` 형식으로 설정합니다. `http://localhost:3000` 및 `http://localhost:3000/admin.html`로 테스트하세요. 로컬에서는 프레임 저장이 `data/admin-frames/`, 공유 사진 저장이 `shared/`를 이용하며 두 폴더는 Git에서 제외됩니다.

## 프레임 이미지 만드는 팁

- 투명 배경의 PNG를 만들어 업로드하는 것을 추천해요(브라우저에서 WEBP로 압축하여 저장).
- 사진이 들어갈 영역은 **투명하게 비워 두고**, 꽃·문구·테두리 등의 장식은 사진 위에 덮이도록 그립니다.
- 포토스트립과 같은 **가로세로 비율**의 이미지를 업로드해야 왜곡이 적습니다.
- 포토부스에 사용되는 개별 사진은 브라우저에서만 렌더링합니다. **사용자가 공유 링크를 직접 생성한 경우에만** 완성 사진이 Blob으로 업로드됩니다.

## 유지보수·보안 메모

- 관리자 주소를 안다고 관리자 권한을 얻을 수 있는 구조가 아닙니다. 변경 API는 서버 측에서 검증합니다.
- 비밀번호 및 세션 비밀 문자열은 **서버 환경 변수**에만 보관합니다. 브라우저 번들, GitHub, README에 실제 값을 넣지 마세요.
- 프레임 이미지와 문구는 일반 사용자에게 공개되는 콘텐츠입니다. 개인 정보가 들어간 이미지는 업로드하지 마세요.
- 프레임 저장은 Vercel Blob Private 저장소에서 유지되므로 재배포해도 지워지지 않습니다. (프로젝트에서 해당 Blob 저장소를 해제하거나 삭제하면 접근할 수 없습니다.)
- 공유 사진 링크는 7일 후 접근할 수 없으며, 실제 파일 삭제는 만료 후 링크 조회 또는 별도 운영 정리에 의존합니다.
- 테스트: `npm run check`. 테스트는 서버 API·관리자 권한·저장/편집/삭제를 검증하며, 실제 Vercel 배포/카메라 권한은 배포 후 확인해야 합니다.


## v5 변경 사항

1. 촬영 단계의 **우리의 사진** 미리보기 카드가 선택한 레이아웃의 실제 사진 슬롯 비율을 자동으로 따라갑니다. 가로 촬영은 가로 썸네일, 세로 촬영은 세로 썸네일로 표시합니다. 모바일에서도 너무 작지 않도록 카드 열 수를 조정했습니다. 각 사진을 누르는 재촬영 기능은 그대로 유지합니다.
2. 출력 Canvas 사진 슬롯을 둘러싸던 **얇은 흰색 선(3px stroke)** 을 제거했습니다. 프레임 배경색·기존 레이아웃·관리자 프레임 기능은 그대로 유지합니다.


## v6 변경 사항 (2026-11-13)

1. **전·후면 카메라 전환:** 촬영 화면의 `↺ 후면 카메라` 버튼을 누르면 모바일에서 후면 카메라를 요청합니다. 전면 카메라는 좌우 반전 미리보기/저장을 사용하고, 후면 카메라는 좌우 반전하지 않습니다. 카메라 변경 시 이미 찍은 사진은 유지됩니다. 후면 카메라를 사용할 수 없으면 전면으로 복귀하려고 시도합니다. 실제 동작은 기기 및 브라우저의 카메라 지원에 따라 달라질 수 있습니다.
2. **모바일 꾸미기 미리보기 고정:** 화면 상단 앱 헤더(66px) 아래에 사진 미리보기가 고정됩니다. 프레임 카테고리·필터·텍스트를 아래로 스크롤하면서 사진 변화가 실시간으로 반영됩니다. 미리보기 높이를 화면 높이의 약 28% (160~260px)로 제한해 조작 공간을 확보했습니다. 데스크톱도 화면 높이에 맞춰 크기를 조절합니다.
3. **카카오톡 인앱 브라우저 저장 대안:** 기본 PNG 다운로드는 유지하되, 카카오톡 브라우저에서는 지원 시 **휴대폰 기본 공유 메뉴**를 먼저 호출합니다. iOS에서는 data URL 저장을 추가로 시도하고, 저장되지 않으면 완성 이미지를 크게 띄워 길게 눌러 저장하도록 안내합니다. Android 카카오톡 WebView에서는 Blob/data URL 다운로드를 지원하지 않을 수 있습니다. 앱의 제한을 완전히 해제할 수 없으므로 크롬·사파리 같은 기본 브라우저 사용이 가장 안정적입니다.

### 업데이트 배포하기

기존 v5 ZIP이 아니라 **v6 ZIP을 압축 해제하여 GitHub 저장소 최상위 파일 전체와 교체**한 후 커밋하세요. Vercel이 저장소와 연결돼 있다면 변경사항을 자동 재배포합니다. `vercel.json`, `public/`, `api/`는 루트에 있어야 합니다. 관리자 비밀번호나 토큰은 기존 Vercel 환경 변수에 보관하세요.
